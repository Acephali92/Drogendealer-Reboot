# Drogendealer-Reboot

Neuauflage des Handels- und Wirtschaftsspiels als Multiplayer-Browserspiel.

## Dokumentation

- [Game Design – alle Spielsysteme mit Formeln, Parametern und Beispielrechnungen](docs/game-design/README.md)

Die Spielregeln sind in `docs/game-design/` spezifiziert; alle Zahlenwerte stehen in
`docs/game-design/parameters.toml`. Prüfung der Formeln und Beispiele:

```bash
python3 docs/game-design/tools/verify.py
```
